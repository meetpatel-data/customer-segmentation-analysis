# customer-segmentation-analysis
Customer Segmentation using RFM analysis on Superstore sales data 

📊 Customer Segmentation Analysis (RFM Model)
🔎 Project Overview

This project analyzes customer purchasing behavior using the RFM (Recency, Frequency, Monetary) segmentation model to identify high-value customers, retention opportunities, and potential churn risks.
The analysis was performed using SQL (SQLite) for data processing and Power BI for visualization.

🎯 Objectives

Identify best customers and revenue contributors

Detect at-risk or inactive customers

Understand customer value distribution

Support targeted marketing and retention strategies

🧰 Tools & Technologies

SQL (SQLite) → Data cleaning, aggregation, RFM scoring

Power BI → Dashboard visualization

Excel/CSV → Data export and preparation

🧠 Methodology (RFM Model)

Recency – Days since last purchase
Frequency – Number of orders per customer
Monetary – Total sales value per customer

Customers were segmented into:

Champions

Loyal Customers

Potential Loyalists

New Customers

At Risk

Lost Customers

Segments were ordered using business lifecycle logic for clearer business interpretation.

📈 Key Insights

Champions contribute the highest revenue and profit

Significant number of customers fall into At Risk / Lost segments

Average recency suggests opportunities for re-engagement campaigns

Top customers identified for targeted retention strategies
